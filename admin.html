Shared Backend (Orders + Customers + Products)

This connects every visitor's device to the same Google Sheet. It's set in the site's code (js/data.js → BACKEND_URL) rather than here, so that it's identical for every visitor — a value only saved in this Settings screen would only ever apply to your own browser, which is why changes weren't showing up on other devices before.

To set or change it: open js/data.js, edit the BACKEND_URL constant near the top, then push the change to GitHub so Vercel redeploys. See /apps-script/Code.gs and the README for full setup steps.
